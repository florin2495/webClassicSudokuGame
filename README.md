# Classic Sudoku

Sudoku pe telefon, în trei variante: clasic 9×9, Samurai (5 grile 9×9 legate prin colțuri) și Bradul de Crăciun
(grilă cu bucăți neregulate). Alegi dificultatea: ușor, mediu sau greu. Fără reclame, fără cont, merge și fără internet.

- Joacă: https://games.hailatat.icu/classicsudoku
- Se instalează ca aplicație separată (Chrome pe Android: butonul „📲 Instalează pe telefon” sau meniul ⋮ → Instalează aplicația).
- Când apare o versiune nouă, sus apare butonul „🔄 Versiune nouă – Reîncarcă”. Jocul în curs rămâne salvat.

Next.js 16, deployed on Vercel under `basePath: "/classicsudoku"` behind the haiLaTăticu hub. See `CLAUDE.md` for details.
